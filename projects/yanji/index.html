项目介绍

研迹是一款面向导师与学生的科研协同应用，将科研过程中的阶段任务、周报、论文资料和 AI 辅助放在同一个工作空间里。

项目由 Flutter Android 客户端、Java 业务后端和独立 AI Agent 服务组成。客户端提供总览、工作、资料、AI 助教和个人信息等入口，后端负责业务数据、权限与文件管理，Agent 负责基于授权资料的科研辅助任务。

主要功能

模块 功能
师生协同 导师与学生账号、课题组关系及指导相关页面
阶段与任务 查看科研阶段、任务状态和进度，记录阶段工作
周报与科研记录 整理周报、科研跟进和经验记录
论文与资料 论文阅读、资料上传与解析、附件存储和访问
AI 科研辅助 围绕科研问答、阶段规划和科研跟进发起 Agent 任务
运行记录 查看 Agent 运行过程与历史结果

技术栈

层次 技术与用途
移动客户端 Flutter / Dart；Riverpod 管理状态，GoRouter 组织页面路由，Dio 请求后端接口
业务后端 Java / Spring Boot；处理业务接口、身份与权限、数据和资料管理
AI Agent Java / Spring AI；通过模型网关调用大模型，执行证据检索与科研辅助流程
数据与文件 MySQL 保存业务数据，MinIO 保存附件
部署与验证 Maven 构建，PowerShell 脚本完成配置、数据库初始化、服务启动及健康检查

系统如何协作

手机通过业务后端访问应用功能。Agent 与文件存储由后端对接，客户端不需要直接连接这些内部服务。仓库提供的本地部署方案让 Windows 电脑运行服务，Android 手机在同一局域网内访问。

实现中值得记录的设计

业务服务与 Agent 分离

业务后端与 Agent 是两个独立的 Java 工程。身份、权限和业务数据由后端管理，模型调用与科研辅助流程集中在 Agent 中，便于分别配置和维护。

围绕授权资料组织 AI 上下文

Agent 先读取任务的授权上下文，再检索并筛选可使用的证据。部分场景在证据不足时返回补充资料提示，避免直接生成缺少依据的结论。基础部署采用关键词检索，混合检索需要额外配置嵌入服务。

跟踪异步任务的运行过程

Agent 使用任务认领、租约和心跳机制确认执行状态，并记录上下文读取、规划和检索等运行事件。客户端提供运行页面与历史入口，方便查看请求的处理过程。

把本地部署步骤脚本化

仓库中的 backend-java/deploy/ 集中了配置、数据库初始化与迁移、构建、服务启动和部署检查脚本。部署说明也覆盖了 Android 安装和局域网连接流程。
