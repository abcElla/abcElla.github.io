项目背景

刷题、学习技术栈和做项目会留下许多零散记录。这个博客把它们放在同一个空间里：既方便回顾知识，也能展示项目的实现过程。

站点采用 Hexo + GitHub Pages：Markdown 负责写作，Hexo 生成静态页面，GitHub Pages 提供在线访问。在线地址是 abcella.github.io。

Hexo 如何生成博客

Hexo 将文章内容、站点配置和主题模板组合成静态 HTML、CSS 与 JavaScript。生成结果放在 public/，浏览器访问的是这些文件。

文章更新和主题改动都需要重新生成页面，再发布生成结果。

四、发布到 GitHub Pages

个人站点使用与账号对应的 <username>.github.io 仓库。本站的发布仓库是 abcElla/abcElla.github.io。

在仓库的 Settings → Pages 中设置发布来源，选择实际存放生成文件的分支和目录。本站生成后的 index.html 位于发布分支根目录，并保留 .nojekyll 文件。

发布前先生成静态文件：

本站使用 .deploy_git/ 保存发布仓库的本地副本。发布时先获取远端更新并快进合并，再把 public/ 的内容复制进去，通过普通 Git 提交和推送更新站点。推送后检查 GitHub Actions 的 Pages 构建结果，最后打开线上地址验证页面和资源。

这里需要区分两份内容：source/、themes/ 和构建脚本是博客源码，public/ 是生成结果。线上仓库中的静态网页不能代替源码备份。

粉色主题与 Loopy 首页

主题使用 EJS 模板和 CSS 组织页面，部分按钮、卡片与手机导航通过 Vue 和 Element Plus 增强。首页只保留顶部导航与 Loopy 横版闯关游戏，游戏使用 Canvas 渲染，并支持键盘与触屏操作。

Notion 同步与专题整理

Notion 中的笔记通过本地同步工具转换为 Markdown，附件保存为本地资源。页面的父子关系用于生成目录和面包屑；题解与总结页从已有内容生成，避免重复维护多份笔记。

全文搜索与内容标签

构建时提取文章标题、正文和小标题，生成本地搜索索引。访客可以按分类和内容标签筛选，搜索结果直接跳到原文对应章节。搜索在浏览器中完成，不需要单独部署搜索服务。

维护中的几个注意点

  • 先检查构建结果：本地预览正常后，再检查生成文件和线上部署结果。
  • 保留固定链接：调整标题或内容分类时，尽量让已有文章地址继续可用。
  • 区分来源与知识标签：Notion 是笔记来源；Java、Redis、回溯等才是用于查找内容的标签。
  • 保护本地配置：同步令牌留在本地，发布目录只包含生成后的公开页面和资源。
