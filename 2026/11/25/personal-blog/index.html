给学习和想法，搭一个自己的小站

# Hexo# GitHub Pages# 个人博客

为什么搭建这个博客

学习过程中会留下解题思路、技术笔记和项目记录。我想把这些内容放在一个自己的空间里，方便整理，也方便以后回顾。

这个博客基于 Hexo + GitHub Pages 搭建，这里记录它的结构与后续计划。

这个小站放什么

栏目 内容
算法笔记 题解、解题方法、复杂度分析和专题总结
技术笔记 编程语言、框架、工具，以及实践中的问题排查
项目实践 做过的项目、实现过程、设计取舍与复盘

技术组成

  • Hexo：把 Markdown 文章生成静态网页。
  • Markdown：编写文章，通过分类和标签组织内容。
  • GitHub Pages：托管生成后的静态站点。
  • 本地主题：统一首页、栏目页与文章页的布局和样式。

这一版的页面结构

首页提供三个栏目入口、项目展示和最近更新。文章页保留清晰的正文、代码排版和目录；项目记录与相关技术笔记可以通过链接串联。

接下来想完善的事

  • 整理第一组算法题解和技术笔记。
  • 为后续项目补充截图、源码地址与使用说明。
  • 随着内容增加，逐步整理专题与学习路线。
